# 项目范围

## 研究目标

研究液体在微/纳米版图中的浸润与外压挤入过程，回答：

1. EC1XT240沟槽中液体前沿如何随时间推进？
2. 黏性、毛细作用、气相出口和额外等效阻力分别有什么影响？
3. 回字形结构是否产生界面钉扎、死角和困气？
4. 沟槽宽度、间距及排列改变后，填充速度和残余气体如何变化？

## 首批目标

- 第一目标：`SIM-EC1XT240.OAS`。
- 第二目标：`SIM-H.OAS`。
- 后续扫描：EC1XT280/300/350/400、K系列和三个复杂矩形版图。

## 模型层级

### L0：解析尺度检查

计算狭缝渗透率、毛细压力、黏性压降、Reynolds数、Capillary数和可能的Knudsen数，为数值结果提供量级边界。

### L1：二维显式直槽

用 `120 nm x 100 um` 竖直截面验证阻力、界面、接触角与压力挤入。该模型是验证器，不代表完整平面版图。

### L2：二维参数研究

分别研究排气、封闭、压力、接触角、网格和等效Darcy对照。

### L3：三维代表单元

引入OAS平面结构和100 um深度，研究横向流动、转角、钉扎与困气。只做代表单元或裁剪区域，不直接解析完整1 mm版图。

### L4：版图比较

在统一物性、边界、网格标准和输出指标下比较版图。

## 暂不包含

- 未标定的分子动力学或DSMC替代模型；
- 把OpenFOAM 350结果逐字段翻译为OpenLB；
- 未验证的完整1 mm x 1 mm x 100 um纳米分辨率计算；
- 在气体完全封闭时把不可压相场结果称作真实可压缩困气模拟；
- 在不知道液体和墙材时给出唯一接触角或唯一压力预测。

## 阶段完成标准

每个阶段必须有：输入配置、可复现命令、日志摘要、机器可读指标、理论或独立数值对照、PASS/FAIL和局限性说明。

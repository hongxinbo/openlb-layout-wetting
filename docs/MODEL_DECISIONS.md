# 模型决策记录

## D001：建立独立长期仓库

- 状态：已采用。
- 决策：本项目使用 `openlb-layout-wetting`，不并入旧 `nanochannel-openlb`。
- 原因：两者的几何、长度尺度、液体、边界和结论能力不同。

## D002：先二维再三维

- 状态：已采用。
- 决策：二维直槽用于验证；真实EC1XT240与SIM-H性能结论使用三维代表单元。
- 限制：二维直槽不能表达平面转角、分叉和困气死角。

## D003：显式阻力基线不叠加Darcy

- 状态：已采用。
- 决策：首个显式墙体模型关闭额外Darcy项。
- 原因：壁面黏性已经产生几何阻力；未标定Darcy会双重计数。

## D004：先排气后封闭

- 状态：建议采用，待确认真实边界。
- 决策：第一数值基线允许气体排出；封闭困气单独建模。
- 原因：先隔离界面、润湿和液体阻力，再引入气体压缩/溶解闭合。

## D005：旧350只作来源审计

- 状态：已采用。
- 决策：保留可追溯候选物性，不复制旧网格、阻力和运动作为新基线。
